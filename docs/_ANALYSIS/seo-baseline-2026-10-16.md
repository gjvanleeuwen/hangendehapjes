## How to compare later

1. `bun run gsc:pull -- --start <28 days before> --end <3 days ago>` (with `CLOUDSDK_CONFIG=/Users/GijsvanLeeuwen/.config/gcloud-hangendehapjes-seo`).
2. Compare the same queries and pages against this file; new pages (`/catering/bruiloft`, `/catering/bedrijfsfeest`) start from zero.
3. Optional, about $3.50: re-run `uv run scripts/seo-research/research.py all --max-spend 5` for fresh SERP, Maps and backlink snapshots.
4. Check cannibalisation: in the GSC query-page data, `tiramisu bruiloft` and `bruidstaart` queries should keep landing on their own blog pages, not on `/catering/bruiloft`.

Caveats: low-volume queries swing a lot between 28-day windows; GSC positions are averages; desktop snapshot and GSC (mostly mobile) differ.
